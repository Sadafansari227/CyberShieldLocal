# 🛡️ CyberShield Local

CyberShield Local is an Android application designed to help users identify cyber threats such as phishing links, suspicious SMS messages, and online scams.

## 🚀 Features

- Detect suspicious SMS messages
- Check phishing URLs
- Report scam messages
- Modern UI built with Jetpack Compose
- Fast and lightweight

## 🛠️ Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3

## 📱 Requirements

- Android Studio
- Android SDK 24 or higher
- Android Emulator or Physical Android Device

## ▶️ Steps to Run the App

1. Clone the repository

```bash
git clone https://github.com/Sadafansari227/CyberShieldLocal.git
```

2. Open the project in Android Studio.

3. Wait for Gradle Sync to complete.

4. Start an Android Emulator or connect an Android phone.

5. Click the **Run ▶️** button.
